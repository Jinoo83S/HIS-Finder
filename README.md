# HIS Finder

기존 Firebase Authentication의 학교 Google 계정을 사용합니다. 정적 화면은 GitHub Pages에 배포할 수 있으며 Google Apps Script가 시트 연동을 처리합니다. Firebase 프로젝트의 Spark 요금제를 유지할 수 있습니다.

## 백엔드 배포

1. 세 원본 시트에 읽기 권한이 있는 학교 계정으로 **새 독립형 Apps Script 프로젝트**를 만듭니다. 기존 웹 앱은 그대로 운영하면서 새 프로젝트를 테스트할 수 있습니다.
2. `apps-script/Code.gs`와 `apps-script/appsscript.json`을 추가합니다. 매니페스트가 보이지 않으면 프로젝트 설정의 매니페스트 표시를 켭니다.
3. 프로젝트 설정의 **스크립트 속성**에 다음 값을 입력합니다.

   | 이름 | 값 |
   | --- | --- |
   | `FIREBASE_WEB_API_KEY` | `his-main` Firebase 웹 앱 설정의 `apiKey` |
   | `ADMIN_EMAIL` | 기본 관리자 학교 이메일 |
   | `SOURCE_URLS` | `{"courses":"…","schedule":"…","attendance":"…","clinic":"…"}` 형태의 원본 주소. 수강 명단과 수업 배정은 같은 문서를 지정할 수 있습니다. |
   | `FIREBASE_LOOKUP_API_KEY` | 선택 사항. 웹 키가 HTTP 리퍼러로 제한된 경우, 같은 Firebase 프로젝트에서 서버의 Identity Toolkit 계정 조회를 허용하는 별도 키를 여기에 지정합니다. |

4. **배포 → 새 배포 → 웹 앱**에서 **다음 사용자로 실행 → 나**, **액세스 권한 → 모든 사용자**(로그인 전 호출 가능)를 선택합니다. 공개 진입점은 버전과 Firebase 웹 설정만 제공하며, 학생 자료와 관리자 기능은 서버에서 Firebase 토큰 및 학교 이메일을 확인합니다. 조직 정책으로 이 옵션이 숨겨져 있으면 조직에서 허용하는 배포 경로가 필요합니다.
5. 새로 발급된 `/exec` URL을 `config.js`에 저장합니다. Firebase Authentication의 승인된 도메인에 GitHub Pages 호스트가 포함되어 있는지 확인합니다.
6. 새 화면에서 관리자 로그인 후 **시트 탭·헤더 확인**을 실행합니다. 탭 이름은 지정 시 우선하며, 비어 있으면 URL의 `gid`로 찾습니다. 학기를 입력하고 **설정 저장 → 시간표 연동**을 실행합니다.

## 원본 시트 구조

| 구분 | 기본 구조 | 처리 |
| --- | --- | --- |
| 수강 명단 | `Raw_Cou` A 이름, B 학년, C 반, J 번호, K–N 과목명, Q 수강 코드 | 학기별 관리자 연동 |
| 수업 배정 | `시간표_Data` A 학년, B 반, C 요일, D 교시, E 수강 코드, F 교사, G 교실, I 예비교실 | 학기별 관리자 연동 |
| 출결 | 이름·날짜·출결 상태 열 또는 날짜별 열. 학년·반·번호·교시·시간이 있으면 함께 매핑 | 오늘 자료 최대 60초 캐시. 학생 화면에서 30초마다 확인, 수동 새로고침 시 즉시 읽기 |
| 보건실 | 이름·방문 날짜 열. 학년·반·번호가 있으면 함께 매핑 | 조회마다 원본을 읽고 오늘 방문 여부만 반환 |

출결과 보건실은 헤더를 자동 인식하며, 필요한 경우 열 위치를 지정할 수 있습니다. 예를 들어 `NAME=B,DATE=A,STATUS=E,PERIOD=F`를 입력합니다. 날짜는 연도를 포함해야 합니다. 동명이인을 식별할 수 없는 기록은 확인 필요로 표시합니다.

시간표 캐시는 실행 계정이 처음 연동할 때 만든 비공개 스프레드시트에 저장됩니다. 소스 구조를 바꾸면 탭 및 열을 다시 확인하고 시간표는 수동으로 재연동합니다. 관리자 설정에서 중·고등별 월–목, 금요일, 단축수업 시간과 단축수업 날짜를 변경할 수 있습니다.

정적 코드에는 학생 데이터, 원본 주소, Firebase 웹 키를 저장할 필요가 없습니다. 전환 전 학교 계정과 외부 계정, 관리자 설정, 동명이인, 당일 출결 변경을 실제 시트로 각각 확인하세요.
